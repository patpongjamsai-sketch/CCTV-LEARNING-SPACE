# แผนสร้างเกมฝึกเข้าหัวสาย RJ45 CAT6

## เป้าหมาย

สร้างเกมฝึกปฏิบัติสำหรับผู้เรียนวิชากล้องวงจรปิดบนระบบเครือข่าย ให้ทำสายตรง T568B ทั้งสองปลายด้วยตนเองครบกระบวนการ ตรวจ Wiremap และแก้หัวที่ผิดก่อนเชื่อมต่อกล้อง IP/PoE โดยยึดใบงาน `ใบงาน_Unit1.2_w02_CCTV_UTP_RJ45.docx` เป็นลำดับการสอนหลัก เกมนี้เป็นภารกิจ RJ45 เฉพาะทางใน Room 103; คะแนนที่นำไปใช้กับระบบรายวิชาต้องเป็นไปตามเกณฑ์ Room 103 ที่ครูกำหนด ไม่เพิ่มคะแนนรายวิชาอีกชุดโดยอัตโนมัติ

## แนวเกมและเทคโนโลยี

- เกมจำลองโต๊ะช่างแบบ 3D ในเว็บไซต์ Next.js ปัจจุบัน ใช้ React Three Fiber สำหรับสาย หัว RJ45 เครื่องมือ และเครื่องทดสอบ ใช้ React DOM สำหรับคำสั่ง ขั้นตอน คำใบ้ และผลตรวจ
- ผู้เล่นหยิบ วัด ตัด ปอก จัดเรียง สอด ย้ำ และทดสอบด้วยการคลิก/ลากหรือปุ่มคีย์บอร์ดที่เทียบเท่าได้ ขั้นตอนที่ต้องการความแม่นยำแสดงภาพขยายหัวและพิน 1–8
- กติกาและสถานะการทำงานอยู่ในโมดูลเกมแยกจากภาพ 3D เพื่อให้ผลตรวจเหมือนกันไม่ว่าผู้เรียนใช้เมาส์ คีย์บอร์ด หรือหน้าจอสัมผัส
- แบ่ง Learn (สาธิตพร้อมเหตุผล), Practice (ฝึกพร้อมคำใบ้), Assessment (ไม่มีเฉลยระหว่างทำ) โดยใช้ภารกิจเดียวกันแต่ต่างระดับการช่วยเหลือ

## วงจรการเล่น

รับใบงาน/สถานการณ์กล้อง IP → เลือกเครื่องมือและหัวให้เข้ากับสาย → ทำปลาย A → ทำปลาย B → ตรวจสาย → อ่านข้อผิดพลาด → ตัดหัวเสียและทำใหม่เฉพาะปลายที่ผิด → ติด Cable ID และส่งผล ผู้เรียนกลับมาฝึกซ้ำได้โดยยังเห็นข้อผิดพลาดครั้งก่อนในโหมดฝึก

## ภารกิจ 8 ขั้นตามใบงาน

| ขั้น | การกระทำของผู้เล่น | สิ่งที่เกมตรวจและแสดงผล |
|---|---|---|
| 1 ปลอดภัยและเลือกวัสดุ | ตัด/ถอด PoE ก่อนจับปลายสาย เลือกสาย CAT6 หัว RJ45 ที่ตรงกับแกนสาย คีมย้ำและอุปกรณ์ป้องกัน | ถ้ายังมีไฟหรือหัวไม่เข้ากับสาย หยุดขั้นตอนพร้อมอธิบายเหตุผล |
| 2 วัดและตัด | วัดระยะตามทางเดิน เผื่อสายซ่อมบำรุง ตัดปลายฉาก และติดป้ายชั่วคราวสองด้าน | ตรวจความยาวตามโจทย์ ปลายตัด และการจับคู่ป้าย A/B |
| 3 สวมปลอกและปอก | สวม boot/ชิ้นส่วนกันน้ำก่อน เลือกระยะปอกตามหัวที่เลือก แล้วใช้คีมปอก | ตรวจการลืมปลอก ระยะปอก และรอยบาดฉนวน/แกนทองแดง; ค่าแนะนำต้องอิงหัวที่ใช้จริง |
| 4 เรียงสี | คลายเกลียวเท่าที่จำเป็น ลาก 8 เส้นเข้าแถว T568B และตัดปลายเสมอกัน | ตรวจมุมมองหัวให้เห็นพิน 1–8 ชัด ตรวจลำดับ ขาวส้ม–ส้ม–ขาวเขียว–น้ำเงิน–ขาวน้ำเงิน–เขียว–ขาวน้ำตาล–น้ำตาล และระยะคลายเกลียว |
| 5 สอดหัว | เลื่อนเส้นทั้งแปดเข้ารางหัวและดันจนสุด | ตรวจแต่ละเส้นถึงหน้าสัมผัส เปลือกนอกเข้าใต้เดือยรัด และลำดับสีไม่เปลี่ยน |
| 6 ย้ำสองด้าน | ใส่หัวให้ถูกช่อง กดย้ำเต็มจังหวะ ตรวจแรงยึดเบื้องต้น แล้วทำซ้ำปลาย B | ย้ำแล้วแก้การเรียงสีไม่ได้ ต้องตัดหัวนั้นทิ้งก่อนทำใหม่; ตรวจปลาย A และ B แยกกัน |
| 7 ทดสอบ | เสียบสองปลายเข้าตัวส่ง/ตัวรับ กดทดสอบและอ่าน LED/Wiremap 1→1 ถึง 8→8 | สร้างผลจากสถานะสายจริง เช่น Open, Short, Miswire, Crossed Pair; ให้ผู้เรียนระบุพินและสาเหตุ ไม่เฉลยทันทีในโหมดประเมิน |
| 8 ซ่อมและส่งงาน | เลือกปลายที่ผิด ตัดหัวเสีย เข้าหัวใหม่ ทดสอบซ้ำ ติด Cable ID ถาวรและป้องกันความชื้นตามโจทย์ | ผ่านเมื่อ Wiremap ถูกครบ ไม่มีความผิดพลาดบังคับ และบันทึกผลการทดสอบซ้ำ; จึงอนุญาตให้ต่อกล้อง/PoE |

## ข้อผิดพลาดและคำใบ้

- สถานการณ์ฝึก: สลับพิน 3/6, เส้น 7 ขาด, ลัดวงจร, ปอกจนแกนเสีย, สอดไม่สุด, เปลือกไม่อยู่ใต้เดือย, ใช้หัวไม่ตรงสาย, ลืมปลอกกันน้ำ และสลับป้ายปลายสาย
- คำใบ้ 3 ระดับ: ชี้ขั้นที่ควรตรวจ → ชี้ชนิดความผิดพลาด → แสดงวิธีแก้พร้อมภาพ ในโหมด Assessment บันทึกจำนวนคำใบ้และไม่เปิดเฉลยก่อนส่ง
- ความผิดพลาดที่เกี่ยวกับไฟ PoE หรือความปลอดภัยต้องหยุดการกระทำและให้แก้ก่อน ไม่ชดเชยด้วยคะแนนส่วนอื่น

## การประเมินและหลักฐาน

- รูบริกเกม 100 คะแนนเพื่อใช้ให้ Feedback ภายในเกม: เตรียมงาน/ความปลอดภัย 15, วัดตัดปอก 15, เรียงสีและรักษาคู่สาย 20, สอดหัวและย้ำสองปลาย 20, ทดสอบ/วินิจฉัย/ซ่อม 20, ป้ายและบันทึกงาน 10
- ผ่านภารกิจเมื่อได้อย่างน้อย 70 คะแนน **และ** ผ่านข้อบังคับ: ตัด PoE ก่อนทำ, หัวเหมาะกับสาย, T568B ทั้งสองปลาย, Wiremap 1→1 ถึง 8→8 ครบ, ไม่มี Short/Open, ทดสอบซ้ำหลังซ่อม และติด Cable ID ครบ หากทำไม่ผ่าน ให้บอกขั้นที่ต้องฝึกใหม่
- เก็บลำดับการกระทำ เวลา จำนวนครั้งที่ตัดหัว จำนวนครั้งที่ย้ำ ผลทดสอบแต่ละครั้ง ข้อผิดพลาด คำใบ้ที่ใช้ และคำตอบวินิจฉัย เพื่อให้ครูเห็นว่าผู้เรียนทำเองทุกขั้น
- เมื่อเชื่อม Room 103 จริง ให้ส่งเหตุการณ์และคำตอบดิบไป Backend; Backend คำนวณคะแนน สถานะผ่าน และสิทธิ์ปลดล็อกตามแผน Room 103 และครูตรวจผลได้จาก Dashboard ไม่ใช้สถานะใน Browser เป็นหลักฐานยืนยัน

## หน้าจอและสื่อ

1. โต๊ะช่าง 3D: สายสองปลาย คีมตัด/ปอก คีมย้ำ หัว CAT6 boot ป้าย เครื่องทดสอบ และแหล่ง PoE
2. ภาพขยายหัว RJ45: พิน 1–8 พร้อมมุมมองที่ไม่กำกวม ปุ่มหมุนดูหัว และสีที่มีชื่อกำกับ ไม่อาศัยสีเพียงอย่างเดียว
3. แผงภารกิจขนาดกะทัดรัด: ขั้นปัจจุบัน เครื่องมือที่ถือ คำใบ้ และปุ่มย้อนดูหลักการ โดยไม่บังพื้นที่ลงมือทำ
4. จอ Cable Tester: LED สองฝั่งและตาราง Wiremap ที่สัมพันธ์กับสายที่ผู้เรียนประกอบจริง
5. สรุปงาน: ขั้นที่ผ่าน/ผิด ภาพผลตรวจ คำอธิบายเหตุผล คำถามตรวจความเข้าใจ และแบบบันทึกงานที่พิมพ์/ส่งได้

ใช้ภาพ 8 ขั้นที่มีอยู่ใน `ใบงานการทดลอง/ภาพประกอบ_RJ45_8ขั้นตอน/` เป็นภาพสอนและภาพอ้างอิงระหว่างทำ พร้อมสร้างโมเดล/ภาพขยายเฉพาะจุดที่ภาพเดิมอธิบายการสอดสายหรือรอยย้ำไม่พอ

## ลำดับพัฒนา

1. ยืนยันเกณฑ์ CAT6 หัวต่อ เครื่องมือ ระยะปอก และรูบริกกับใบงานและอุปกรณ์จริงของห้องเรียน
2. สร้างกติกาเกมและสถานะสายสองปลาย พร้อมชุดกรณี Open/Short/Miswire และข้อผิดพลาดจากการประกอบ
3. ทำภารกิจ 8 ขั้นแบบโต้ตอบและโหมด Learn/Practice/Assessment พร้อมเมาส์ คีย์บอร์ด และจอสัมผัส
4. ทำภาพโต๊ะช่าง/หัวขยาย/เครื่องทดสอบ แล้วเชื่อมการเคลื่อนไหวกับกติกา
5. เชื่อม Room 103, Backend และ Teacher Dashboard โดยรักษาระบบคะแนน/การอนุมัติเดิม
6. ทดลองกับผู้เรียน: ให้ทำสายถูกหนึ่งเส้น ซ่อมสายผิดหนึ่งเส้น และอธิบายผล Tester ด้วยตนเอง; ปรับคำใบ้และความยากจากข้อผิดพลาดจริง

## เกณฑ์ตรวจรับ

- นักเรียนทำครบทั้ง 8 ขั้นกับปลาย A และ B โดยไม่ใช้ปุ่มเติมคำตอบอัตโนมัติในโหมด Assessment
- สายที่ประกอบถูกให้ผล 1→1 ถึง 8→8; ความผิดพลาดที่จำลองให้ผลตรวจสอดคล้องและแก้ได้ด้วยการตัดหัวใหม่
- ข้อบังคับความปลอดภัยและ Wiremap ทำให้คะแนนสูงอย่างเดียวไม่สามารถผ่านได้
- ครูตรวจลำดับการทำ เวลา ความผิดพลาด ผลทดสอบก่อน/หลังซ่อม และเหตุผลที่ผู้เรียนตอบได้
- หน้าเกมอ่านง่ายบนคอมพิวเตอร์ห้องเรียน และมีวิธีควบคุมที่ไม่ต้องลากวัตถุอย่างเดียว
